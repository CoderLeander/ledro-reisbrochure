# 🌿 Lago di Ledro & Noord-Italië – Exclusieve Reisbrochure 2027

Een luxueus vormgegeven, interactieve en printklare reisbrochure & website voor een 8-daagse reis naar het **Ledrodal**, **het Gardameer** en **het Iseomeer** (13 – 20 juli 2027) met verblijf in **Hotel Lido Ledro**.

---

## 🌟 Belangrijkste Functies van deze Web-Brochure

- **Luxe Magazine Ontwerp:** Geïnspireerd door hoogwaardige reisbladen (Conde Nast Traveler stijl) met warme alpine tinten, serif typografie (*Cormorant Garamond*) en een strakke indeling.
- **Geïntegreerde Referentievideo's:** Direct ingebouwde YouTube-videospeler (lightbox modals) voor de referentieclips (Hotel Lido, Suppen op het meer, Strada del Ponale, Kabelbaan Monte Baldo, Palafitte paalwoningen en Bastione lift).
- **Interactief Reisschema:** Filter per dag (Di 13 t/m Di 20 juli) of bekijk het complete chronologische weekoverzicht met directe reistijden, loopafstanden en wandelroutes.
- **Gastronomische Gids:** Uitgelichte culinaire hotspots per avond (houtovenpizza bij La Finestra, Slow Food bij ELDA, Strangolapreti bij Osteria La Torre, Polenta di patate bij Rifugio al Faggio, en ambachtelijke Carne Salada bij Agritur Calvola).
- **Directe Google Maps Links:** Elke locatie, steiger, lift en restaurant is direct aanklikbaar.
- **1-Klik Print & PDF Dossier:** Geoptimaliseerd met `@media print` CSS om met één klik op de knop een prachtig geformatteerd PDF-reisboek te exporteren of af te drukken.
- **Interactieve Reischecklist:** Handige meeneemlijst met geheugenfunctie in de browser (`localStorage`).

## 🚀 Lokaal Openen & Bekijken

Omdat deze website gebouwd is zonder zware frameworks of build-stappen (zero dependencies), kan je hem direct openen:

### Optie 1: Direct in de browser
Dubbelklik simpelweg op `index.html` of open het bestand in Google Chrome, Microsoft Edge, Safari of Firefox.

### Optie 2: Met een lokale ontwikkelserver (optioneel)
In PowerShell of Command Prompt in deze map:

```powershell
# Met Python:
python -m http.server 8080

# Of met Node:
npx serve .
```
Surf vervolgens naar `http://localhost:8080`.

## 🌐 Gratis Online Hosten als Website (3 Eenvoudige Opties)

### Optie A: GitHub Pages (Aanbevolen)
1. Maak een nieuwe repository aan op [GitHub.com](https://github.com/new) (bijv. `ledro-reisbrochure`).
2. Koppel en push deze lokale repository:
   ```bash
   git remote add origin https://github.com/<jouw-gebruikersnaam>/ledro-reisbrochure.git
   git branch -M main
   git push -u origin main
   ```
3. Ga op GitHub naar **Settings** &rarr; **Pages** &rarr; kies bij *Branch* voor `main` en `/ (root)` &rarr; klik op **Save**.
   *Binnen 60 seconden staat je brochure live op `https://<jouw-gebruikersnaam>.github.io/ledro-reisbrochure/`!*

### Optie B: Netlify Drop (Zonder command line)
1. Surf naar [app.netlify.com/drop](https://app.netlify.com/drop).
2. Sleep de map `ledro-reisbrochure` in het venster.
3. Je website staat binnen 5 seconden live met een gratis HTTPS-adres.

### Optie C: Vercel
Koppel je GitHub repo in [Vercel](https://vercel.com/) voor instant zero-config deployment.
